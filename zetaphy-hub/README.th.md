## ทำงานอย่างไร

- `node build.mjs` คัดลอก hub และทุกแอปลง `dist/` (`/wallet/`, `/swap/`, `/nft/`, `/explorer/`, `/neuro/web/`) แอปแสดงใน **frame ของเว็บเดียวกัน** จึงใช้ที่เก็บกระเป๋าร่วมกัน และ hub ปรับหน้าตาให้ได้
- `embed.css` ทำให้ทุกแอปใช้สีเดียวกับ hub และซ่อนแถบชื่อ ปุ่มภาษา และ footer ของแอปเอง ส่วน `hub.js` พับคำอธิบายยาวๆ เป็นไอคอน "i" ที่แสดงข้อความเมื่อเอาเมาส์ไปชี้หรือกด Tab ไปที่ ลิงก์ไปเว็บของแอปอื่นจะเปิดแท็บของแอปนั้นแทน
- ตัวแอปไม่ได้เปลี่ยน: ถ้าเปิดที่เว็บของแอปเอง (wallet.sawasdeecoin.com และอื่นๆ) หน้าตาเหมือนเดิม
- ภาษา: เมนูเดียว 8 ภาษา (English, 中文, Español, 한국어, 日本語, Русский, Tiếng Việt, ไทย ค่าเริ่มต้นเป็นอังกฤษ) ข้อความอยู่ใน `i18n.js` (hub และแท็บ) และ `pages-i18n.js` (หน้าข้อมูล) ถ้าข้อความไหนขาดจะแสดงเป็นภาษาอังกฤษ hub จะตั้งภาษาของแต่ละแอปแล้วโหลด frame ใหม่
- คำอธิบาย: ทุกตัวเลข ปุ่ม และขั้นตอน มีข้อความเด้งเมื่อชี้ (`data-tip` / `data-tip-key`) ตัวหน้าเว็บจึงมีข้อความสั้น
- ที่อยู่โหนดอ่านจาก `zetaphy-explorer/config.json` (launch เขียนไว้) แล้วบันทึกเป็น `dist/hub-config.json`
- เส้นทาง EVM ของ Saphan (Hyperlane) อ่านจากตารางเชน `zetaphy-chain/hyperlane/saphan-chains.json` และเส้นทางที่ติดตั้งแล้วใน `saphan-routes.json` (อยู่ใน `dist/hub-config.json` ด้วย) เชนที่เพิ่มในตารางจะขึ้นในหน้า Saphan เป็น "วางแผนไว้" แล้วเป็น "ปิด" หรือ "เปิด"
- เส้นทางโทเคนของ Saphan (โทเคนที่เกิดบน ZETAPHY ส่งออกไปเชนอื่น docs/SAPHAN-TOKENS.md) อ่านจาก `tokens` ในตารางเดียวกันและใน `saphan-routes.json` (`saphanTokens` ใน `dist/hub-config.json`) หน้า Saphan แสดงแต่ละโทเคนต่อเชนปลายทาง (BZTPHY แสดงว่าอยู่บน ZETAPHY) และแถบกระเป๋าแสดงใต้โทเคนที่ถืออยู่ (และใต้ ZETAPHY) ว่าส่งออกไปที่ไหนได้

## ขุด ZETAPHY ทดลอง (faucet แบบ proof of work)

เหมือน [faucet PoW ของ Sepolia โดย pk910](https://sepolia-faucet.pk910.de): ให้เบราว์เซอร์คำนวณไม่กี่นาทีแลกเหรียญ **testnet** ฟรี
คนเดียวจึงใช้หลายที่อยู่หรือหลาย IP ดูด faucet จนหมดไม่ได้ นี่**ไม่ใช่การขุด**: ZETAPHY เป็น proof of stake งานนี้ไม่ได้ป้องกันอะไร
เหรียญไม่มีมูลค่า และคำนวณแค่โจทย์ `sha256` ของ faucet นี้ (ไม่ขุดเหรียญอื่น)

- ไม่มีเซิร์ฟเวอร์ของตัวเอง: โหนดตรวจคำตอบเอง (`zetaphy_faucetPow`, `zetaphy-chain/README.th.md`) หน้าเว็บอ่าน `zetaphy_faucetPowInfo`
  และบล็อกล่าสุด แล้วให้ Web Worker (`mine-worker.js` โมดูลจากเว็บเดียวกัน ผ่าน `script-src 'self'` ไม่ใช้ eval ไม่ใช้ wasm) หา nonce ด้วย
  SHA-256 แบบ JavaScript ล้วน (`mine-core.js`) เจอแล้วขอเหรียญให้อัตโนมัติ พร้อมลิงก์ธุรกรรมไป explorer
- ไม่มีอะไรทำงานจนกว่าจะกด **เริ่ม** และ**หยุดชั่วคราวเมื่อแท็บถูกซ่อนหรือเปิดหน้าอื่นใน hub** กลับมาก็ทำต่อ (ทุกครั้งที่ลองเป็นโอกาสใหม่ หยุดไปไม่เสียอะไร)
  หยุดเมื่อกดหยุด เจอคำตอบ หรือออกจากหน้า เลือกเธรดได้ 1 ถึงจำนวนคอร์ (สูงสุด 8) **ค่าเริ่มต้น 2** ใช้แบตให้เลือก 1
- บล็อกที่ใช้จะเปลี่ยนเป็นบล็อกใหม่ทุก 20 วินาทีเมื่ออายุเกินครึ่งที่อนุญาต (100 บล็อก ~8 นาที)

**ความยาก: บิตศูนย์ 30 บิต** (เฉลี่ย 2^30 ≈ 1.07 พันล้านครั้ง) วัดบน Chromium 141 แบบ headless, Xeon 2.1 GHz (4 vCPU แชร์):
SHA-256 JavaScript ใน Web Worker **2.38 MH/s** ต่อ 1 worker (~1.8–2.3 MH/s ต่อ worker เมื่อใช้ 2–4) ส่วน WebCrypto `crypto.subtle.digest`
**0.11 MH/s** ช้ากว่า 20 เท่า หน้าเว็บจึงใช้แบบ JavaScript ล้วน บนเครื่องนี้ใช้ ~7.5 นาที (1 เธรด) / ~4.4 นาที (2 เธรด)
โน้ตบุ๊กรุ่นใหม่เร็วกว่าราว 1.5 เท่า: **~2.6 นาทีด้วย 2 เธรด ~5 นาทีด้วย 1 เธรด** มือถือช้ากว่า 2–4 เท่า เวลาเป็นแบบสุ่ม: 1 ใน 10 ครั้งใช้นานเกิน 2.3 เท่าของค่าเฉลี่ย
ผู้ดูแลโหนดเปลี่ยนความยากได้โดยไม่ต้องออกเวอร์ชันใหม่ (`<home>/config/faucet-pow-bits`, 12–48)

## ทุกแท็บ: ทำงานอย่างไร ไปต่อที่ไหน และงานที่ทำต่อเนื่อง

- **ทำงานอย่างไร** (`flow.js` ข้อความใน `flow-i18n.js`): เหนือทุกแท็บมี 4 ขั้นเป็นไอคอนที่สว่างทีละขั้น
  ตามด้วยแท็บที่ควรไปต่อ พับเก็บได้ และเบราว์เซอร์จำไว้
- **แท็บแผนที่ AI** (`aimap.js`): ฟีเจอร์ AI ทั้ง 35 อย่าง (docs/future/) เป็นการ์ดรูป แบ่งกลุ่ม พร้อมสถานะ
  (ใช้ได้แล้ว ฝึกใช้ รอสัญญา อยู่ในเชน ใช้ผ่านคำสั่ง) และปุ่มเปิดไปยังที่ของแต่ละอย่าง
- **งานที่ทำต่อเนื่อง:** การขุด การสแกนงานที่มีประโยชน์ และการล่าบั๊ก ทำต่อแม้เปิดแท็บอื่น และสลับโหมดในหน้าขุดได้โดยไม่หยุด
  แท็บจะมีจุดสีเขียว และแถบบนมีป้าย "กำลังทำงาน" กดกลับไปได้ ปุ่มพักและหยุดใช้ได้เหมือนเดิม การเปลี่ยนภาษาจะวาดหน้าใหม่และหยุดงาน

## แท็บออฟไลน์: จ่ายเงินและเทรดโดยไม่มีเน็ต (เทสต์เน็ต)

`offline.js` (ตรรกะใน `offline-core.js` ข้อความใน `offline-i18n.js`): กุญแจออฟไลน์แยกต่างหาก เก็บแบบเข้ารหัสในเบราว์เซอร์
(AES-GCM, PBKDF2-SHA256 600,000 รอบ) เซ็นและตรวจเช็คได้โดยไม่ต้องมีเน็ต สร้างคำสั่งสวอปตอนออฟไลน์ให้ใครก็ส่งขึ้นเชนแล้วได้ค่าธรรมเนียม
QR วาดด้วย `vendor/qrcode.js` (MIT ตรึงไว้ใน `vendor/qrcode.json`) เปิดแท็บนี้ครั้งแรกจะลงทะเบียน `sw.js` ซึ่งเก็บเฉพาะโครงหน้าเว็บแบบสถิต
(ไม่เก็บข้อมูลจาก RPC) ฮับจึงเปิดได้ตอนออฟไลน์ และแถบบนจะขึ้นป้ายเมื่อเบราว์เซอร์ออฟไลน์
สัญญาและภัยที่คิดไว้: [docs/future/offline-trading.th.md](../docs/future/offline-trading.th.md)

## เครื่องมือค้นหา (`seo.mjs`)

- **ZETAPHY คืออะไร** หน้า `/about/` และ `/about/<lang>.html` ครบ 8 ภาษา เป็น HTML ธรรมดาที่สร้างจาก
  `about-content.mjs` เครื่องมือค้นหาจึงอ่านได้โดยไม่ต้องรันสคริปต์ แถบด้านข้างของ hub มีลิงก์ไปหน้านี้
- ทุกเว็บมี `robots.txt`, `sitemap.xml`, ลิงก์ canonical ไปโดเมนของตัวเอง, การ์ดแชร์ (`og.png`) และไฟล์ key ของ IndexNow
  ของ hub สร้างโดย `build.mjs` ของเว็บอื่น commit ไว้ในรีโป (แก้ `SITES` แล้วรัน `node seo.mjs --write` มีเทสต์ตรวจให้)
- **Bing, Yandex, Seznam, Naver:** หลัง deploy รัน `node seo.mjs --indexnow` เพื่อแจ้งทุกหน้า
- **Google:** หา sitemap ผ่าน robots.txt เอง ถ้าอยากให้เร็วขึ้น เจ้าของ sawasdeecoin.com เพิ่ม property แบบ *Domain*
  ใน Google Search Console (ระเบียน DNS TXT เดียวครอบคลุมทุกเว็บ) แล้วส่ง `https://<เว็บ>/sitemap.xml` ของแต่ละเว็บ

## ขึ้นเว็บ (Vercel ฟรี)

ตั้ง root ของโปรเจกต์เป็น `zetaphy-hub` framework เลือก "Other" ส่วน `vercel.json` กำหนดคำสั่ง build, header (frame ได้เฉพาะจากเว็บนี้ สคริปต์โหลดได้เฉพาะจากเว็บนี้) และการส่งต่อ Neuro API โดเมน: `app.sawasdeecoin.com` (Cloudflare: CNAME `app` → `cname.vercel-dns.com` แบบ DNS only)

## เทสต์

```
npm ci
npm test            # calldata เทียบ ethers, bech32, จำนวนเหรียญ, ไฟล์ใน dist/, header
npm run test:e2e    # Chromium: ทุกแท็บกับโหนดจำลอง, จอเดียว, ข้อความเด้ง, stake/โหวต, มือถือ;
                    # งานที่มีประโยชน์: สแกน+ล่าฝึกหัด และสัญญาจริงบน EVM ในหน่วยความจำ
npm run build:evm   # สร้าง vendor/evm.js ใหม่ (EthereumJS EVM สำหรับ worker ล่าบั๊ก)
```
