# SWD Pay สำหรับ WooCommerce — คู่มือภาษาไทย (สำหรับเจ้าของร้าน)

ปลั๊กอินสำหรับร้านค้าออนไลน์ที่ใช้ **WordPress + WooCommerce** ให้ลูกค้าจ่ายเงินด้วย **SWD** หรือ **USDC** บน Solana
ผ่าน **Solana Pay** (สแกน QR ด้วยกระเป๋า Phantom / Solflare) เงินเข้ากระเป๋าของร้านโดยตรง ไม่มีคนกลางถือเงิน

English: [README.md](README.md)

## ลูกค้าจะเห็นอะไร

1. ตอนชำระเงิน เลือก "Pay with SWD or USDC (Solana Pay)"
2. หลังกดสั่งซื้อ จะเห็น QR code พร้อมจำนวนเหรียญที่ต้องจ่าย (เลือกแท็บ SWD หรือ USDC ได้)
3. สแกนด้วยแอปกระเป๋า หรือกด "Open in wallet" บนมือถือ แล้วกดยืนยันในกระเป๋า
4. ภายในไม่กี่วินาที หน้าเว็บจะขึ้นว่า "ได้รับเงินแล้ว" และสถานะคำสั่งซื้อเปลี่ยนเป็น "กำลังดำเนินการ" (Processing) อัตโนมัติ

## ระบบตรวจเงินอย่างไร (ทำไมปลอดภัย)

- ทุกคำสั่งซื้อมี "รหัสอ้างอิง" ไม่ซ้ำกัน ฝังอยู่ใน QR
- เซิร์ฟเวอร์ของร้านถามบล็อกเชน Solana เองว่ามีธุรกรรมที่มีรหัสนี้ และ
  ✔ ธุรกรรมสำเร็จ ✔ เงินเข้ากระเป๋าของร้าน ✔ เป็นเหรียญที่ถูกต้อง (ตรวจ mint และทศนิยม) ✔ จำนวนไม่น้อยกว่าที่ต้องจ่าย
  ✔ ธุรกรรมนี้ไม่เคยถูกใช้จ่ายคำสั่งซื้ออื่นมาก่อน
- ถ้าลูกค้าจ่ายขาด คำสั่งซื้อจะ **ยังไม่ถูกทำเครื่องหมายว่าจ่ายแล้ว** และมีบันทึกพร้อมลิงก์ธุรกรรมให้ร้านตรวจ
- ปลั๊กอินรู้แค่ "ที่อยู่กระเป๋าสาธารณะ" ของร้าน **ห้ามใส่ seed phrase หรือ private key ลงใน WordPress เด็ดขาด**

## ติดตั้ง (ทำครั้งเดียว)

1. ให้นักพัฒนารัน `sh scripts/zip.sh` จะได้ไฟล์ `dist/woocommerce-swd-pay.zip`
2. ใน WordPress: เมนู **ปลั๊กอิน → เพิ่มใหม่ → อัปโหลดปลั๊กอิน** เลือกไฟล์ zip → ติดตั้ง → เปิดใช้งาน
3. ไปที่ **WooCommerce → การตั้งค่า → การชำระเงิน → SWD Pay** แล้วกรอก:
   - **ที่อยู่กระเป๋า Solana ของร้าน** (คัดลอกจาก Phantom ปุ่ม "Copy address")
   - **RPC URL**: ค่าเริ่มต้นใช้ได้สำหรับทดลอง แต่ร้านจริงควรสมัคร RPC ของตัวเอง (เช่น Helius มีแพ็กเกจฟรี) เพราะของฟรีสาธารณะอาจช้า/ถูกจำกัด
   - เลือกรับ SWD และ/หรือ USDC
   - **วิธีคิดราคา**:
     - *อัตราคงที่* — กรอกเองว่า 1 SWD = กี่บาท และ 1 USDC = กี่บาท (เช่น 36.5)
     - *ราคาตลาด (Jupiter)* — ระบบดึงราคาเป็นดอลลาร์ แล้วคูณด้วยช่อง "store currency per 1 USD" (ร้านเงินบาทใส่อัตราบาทต่อดอลลาร์ เช่น 36.5) ราคาที่เสนอจะหมดอายุใน 15 นาที (ตั้งได้)
4. ติ๊ก **Enable** แล้วกดบันทึก
5. **ทดลองสั่งซื้อจริงด้วยยอดเล็ก ๆ** (เช่น 0.10 USDC) ก่อนเปิดให้ลูกค้าใช้

## ข้อควรรู้

- การโอนบน Solana **ย้อนกลับไม่ได้** ถ้าต้องคืนเงิน ให้ร้านโอนคืนจากกระเป๋าเองแล้วจดบันทึกในคำสั่งซื้อ
- ถ้าลูกค้าโอนเองโดยไม่สแกน QR (ไม่มีรหัสอ้างอิง) ระบบจะตรวจอัตโนมัติไม่ได้ ร้านต้องตรวจและกดเปลี่ยนสถานะเอง
- ปุ่ม "Check Solana Pay payment now" ในหน้าคำสั่งซื้อ (เมนู Order actions) ใช้สั่งตรวจซ้ำได้ทันที
- ระบบตรวจซ้ำอัตโนมัติทุก 5 นาที (ผ่าน WP-Cron) ร้านที่คนเข้าน้อยควรให้ผู้ดูแลโฮสต์ตั้ง cron จริงเรียก `wp-cron.php`
- ภาษีและบัญชี: การรับชำระด้วยคริปโตในไทยอาจมีข้อกำหนดทางภาษี/กฎหมาย ควรปรึกษานักบัญชี

## แล้ว Shopify ล่ะ?

Shopify **ไม่อนุญาต** ให้ติดตั้งปลั๊กอินรับเงินเองแบบนี้ ช่องทางจ่ายเงินในหน้า checkout ต้องเป็นแอปที่ Shopify อนุมัติแล้วเท่านั้น
ทางเลือกคือ:

1. ติดตั้งแอป **Solana Pay for Shopify** (ของ Solana Pay / Solana Labs ร่วมกับ **Helio**) จาก Shopify App Store — รับ USDC ได้
2. ติดต่อ **Helio** เพื่อขอเปิดรับเหรียญ SWD
3. สร้างแอปรับเงินของเราเองบน Shopify (ใช้เวลาและต้องผ่านการตรวจของ Shopify — คุ้มเมื่อยอดขายสูง)
4. ใช้วิธี "ชำระเงินแบบแมนนวล" แล้วส่งลิงก์ Solana Pay ให้ลูกค้า ร้านกดยืนยันเอง

โฟลเดอร์นี้เป็นโค้ดสำหรับ WooCommerce เท่านั้น

## สิ่งที่เจ้าของต้องทำ

- มีเว็บ WordPress + WooCommerce (เวอร์ชัน 8 ขึ้นไป) และกระเป๋า Solana ของร้าน
- (แนะนำ) สมัคร RPC ของตัวเอง เช่น Helius / QuickNode
- ตั้งราคา และทดลองจ่ายจริงยอดเล็กก่อนเปิดใช้
- (ไม่บังคับ) ถ้าต้องการเผยแพร่บน WordPress.org ต้องส่งปลั๊กอินให้ทีม WordPress ตรวจ (ฟรี ใช้เวลาหลายสัปดาห์)
