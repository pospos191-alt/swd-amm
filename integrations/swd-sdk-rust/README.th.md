# swd-sdk สำหรับภาษา Rust (ภาษาไทย)

ชุดเครื่องมือสำหรับนักพัฒนาที่เขียนโปรแกรมด้วยภาษา Rust (เช่น บอท, เซิร์ฟเวอร์, โปรแกรมบน Solana) ให้เรียกใช้บริการของ
**SWD (SAWASDEE COIN)** ได้: ตรวจความเสี่ยงเหรียญ 14 เชน, ตรวจธุรกรรม, ดูจำนวน SWD, สร้างธุรกรรมซื้อ SWD (ยังไม่เซ็น)
และอ่านผลตรวจที่บันทึกไว้บนเชน Solana (SWD Audit Registry)

English: [README.md](README.md)

## ความปลอดภัย

- ไม่ใช้และไม่ขอ private key ใด ๆ ธุรกรรมซื้อ SWD ต้องให้กระเป๋าของผู้ซื้อเซ็นเอง
- ตัวอ่าน Registry ใช้กับโปรแกรมบนเชนที่ **ยังเป็นฉบับร่าง ยังไม่ได้ตรวจสอบ และยังไม่ได้ deploy** — ต้องรอ SWD ประกาศ program id จริงก่อน
- ไม่มีผลตรวจ = "ยังไม่รู้" ไม่ใช่ "ปลอดภัย"

## การทดสอบ

`cargo test` ทำงานแบบออฟไลน์ทั้งหมด (จำลองเซิร์ฟเวอร์ในเครื่อง) ผ่านครบทุกข้อ

## สิ่งที่เจ้าของต้องทำ (ถ้าต้องการเผยแพร่บน crates.io)

1. เข้า https://crates.io แล้วล็อกอินด้วยบัญชี GitHub (ฟรี)
2. สร้าง API token ที่หน้า Account Settings → API Tokens
3. ในเครื่องที่ติดตั้ง Rust: `cd integrations/swd-sdk-rust && cargo login <token> && cargo publish`

ชื่อ crate `swd-sdk` ต้องตรวจอีกครั้งตอนเผยแพร่ว่ายังว่างอยู่ ไม่มีค่าใช้จ่าย
