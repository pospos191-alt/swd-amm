# SWD Guard — ส่วนขยาย Chrome (คู่มือภาษาไทย)

SWD Guard คือส่วนขยาย (extension) สำหรับ Google Chrome ของ SWD (SAWASDEE COIN) ที่ช่วย **เตือนผู้ใช้ก่อน**
จะซื้อเหรียญเสี่ยงหรือเข้าเว็บหลอก

English: [README.md](README.md) · ขั้นตอนส่งขึ้น Chrome Web Store: [STORE_CHECKLIST.th.md](STORE_CHECKLIST.th.md)

## ผู้ใช้จะเห็นอะไร

1. **ป้าย SWD Audit บนหน้าเหรียญ** — เมื่อเปิดหน้าเหรียญบน Solscan, Jupiter, Birdeye, DEX Screener หรือ pump.fun
   จะมีกล่องเล็ก ๆ มุมขวาล่างบอกระดับความเสี่ยง (สูง / ปานกลาง / ต่ำ / กฎไม่พบความเสี่ยง) ถ้าเสี่ยงสูงจะมีข้อความเตือนสีแดง
   และลิงก์ไปดูรายงานเต็มบนเว็บ SWD
2. **ปุ่มตรวจในแถบเครื่องมือ** — กดไอคอนโล่สีเขียว วางที่อยู่เหรียญ, hash ธุรกรรม หรือลิงก์ แล้วกด "ตรวจ"
3. **หน้าจอเตือนเว็บฟิชชิง** — ถ้าเข้าเว็บที่อยู่ในรายชื่อเว็บหลอก จะขึ้นหน้าจอสีแดงเต็มจอ มีปุ่ม "ออกจากเว็บนี้"
   และเมื่อกดไอคอนบนเว็บที่ "ดูเหมือน SWD แต่ไม่ใช่ sawasdeecoin.com" ก็จะเตือนด้วย
4. **รองรับ 8 ภาษา** — ไทย อังกฤษ จีน ญี่ปุ่น เกาหลี เวียดนาม สเปน รัสเซีย (เลือกตามภาษาของเบราว์เซอร์อัตโนมัติ)

## ความปลอดภัยและความเป็นส่วนตัว

- **ไม่แตะกระเป๋าเงิน ไม่อ่าน seed phrase / private key / รหัสผ่าน**
- ส่งออกไปเฉพาะ "ที่อยู่เหรียญหรือ hash ธุรกรรมที่กำลังดู" ไปที่เว็บ SWD เพื่อตรวจ ไม่มีคุกกี้ ไม่มีระบบติดตาม
- ไม่โหลดโค้ดจากอินเทอร์เน็ต (Chrome Web Store ห้ามอยู่แล้ว)
- ขอสิทธิ์น้อยที่สุด: เฉพาะเว็บที่แสดงป้าย + เว็บ SWD + รายชื่อเว็บหลอก ส่วนสิทธิ์ "ทุกเว็บ" เป็น **ตัวเลือกเสริม** ที่ผู้ใช้ต้องกดอนุญาตเองในหน้าตั้งค่า
- นโยบายความเป็นส่วนตัวฉบับเต็ม: [PRIVACY.md](PRIVACY.md)

## ทดลองใช้ในเครื่องตัวเอง (ไม่ต้องส่ง Store)

1. เปิด Chrome พิมพ์ `chrome://extensions` ในช่องที่อยู่
2. เปิดสวิตช์ **Developer mode** (มุมขวาบน)
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์ `integrations/chrome-swd-guard`
4. ลองเปิด `https://solscan.io/token/Cmh2tu6bt5z2a8NKsx6G5WfVmaeQ9f2fcX5VnQbVaGLL` จะเห็นป้าย SWD Audit มุมขวาล่าง

> หมายเหตุ: ตอนนี้เว็บ swd-zetaphy.sawasdeecoin.com ปิดชั่วคราว (Vercel 402) ป้ายจะขึ้นว่า "ยังตรวจไม่ได้ในตอนนี้"
> จนกว่าเว็บจะกลับมาออนไลน์ ส่วนการเตือนเว็บฟิชชิงทำงานได้ทันทีเพราะรายชื่ออยู่ในตัวส่วนขยาย

## การดูแลรายชื่อเว็บหลอก

รายชื่ออยู่ในไฟล์ `data/phishing-domains.json` ตอนนี้มีชื่อเว็บที่ "เลียนแบบชื่อ SWD" 6 ชื่อเป็นตัวอย่าง
**ก่อนส่งขึ้น Store ควรให้ทีมตรวจรายชื่อ** ใส่เฉพาะเว็บที่มีคนแจ้งและตรวจแล้วว่าหลอกจริง
หลังแก้ไฟล์ให้นักพัฒนารัน `node scripts/sync-manifest.mjs` และ `npm test`

ผู้ใช้ที่เปิด "ดาวน์โหลดรายชื่อฉบับล่าสุด" จะได้รายชื่อใหม่ภายใน 1 วันหลังรวมเข้า `main` บน GitHub

## สิ่งที่เจ้าของต้องทำ

1. สมัครบัญชีนักพัฒนา Chrome Web Store (ค่าธรรมเนียมครั้งเดียว **5 ดอลลาร์สหรัฐ**)
2. ทำตาม [STORE_CHECKLIST.th.md](STORE_CHECKLIST.th.md) (ภาพหน้าจอ, นโยบายความเป็นส่วนตัว, เหตุผลการขอสิทธิ์)
3. ให้นักพัฒนารัน `sh scripts/zip.sh` เพื่อได้ไฟล์ `dist/swd-guard-0.1.0.zip` แล้วอัปโหลด
