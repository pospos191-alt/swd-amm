# swd-sdk (ภาษาไทย)

ชุดเครื่องมือสำหรับนักพัฒนา (SDK) ภาษา JavaScript/TypeScript ที่ให้เว็บหรือแอปอื่นเรียกใช้บริการสาธารณะของ
**SWD (SAWASDEE COIN)** ได้ง่าย ๆ — ไม่ต้องมี API key ไม่มีไลบรารีอื่นพ่วง

English: [README.md](README.md)

## ทำอะไรได้บ้าง

| ฟังก์ชัน | ทำอะไร |
| --- | --- |
| `audit(chain, address)` | ตรวจความเสี่ยงของเหรียญ/สัญญา 14 เชน ได้ระดับ (high / medium / low / info) และรายการที่พบ |
| `auditTx(chain, hash)` | ตรวจธุรกรรมหนึ่งรายการว่าย้ายเงินไปไหน มีรูปแบบหลอกลวงที่รู้จักหรือไม่ |
| `supply()` | จำนวน SWD ทั้งหมด และที่หมุนเวียน |
| `buySwdTransaction(...)` | สร้างธุรกรรม "ซื้อ SWD ด้วย SOL" ที่ **ยังไม่ได้เซ็น** ให้กระเป๋าของผู้ซื้อเซ็นเอง |
| `verifyAttestation(...)` | ตรวจลายเซ็นใบรับรองผลการตรวจ (Ed25519 ได้ทันที ส่วน ML-DSA-44 ต้องใส่ตัวตรวจเพิ่ม) |

## ความปลอดภัย

- SDK **ไม่เคยแตะ private key** และไม่เซ็นธุรกรรมใด ๆ
- ผลตรวจเป็นการตรวจอัตโนมัติด้วยกฎตายตัว ไม่ใช่คำแนะนำการลงทุน ระดับ `info` หมายถึง "กฎไม่พบความเสี่ยง" ไม่ได้แปลว่า "ปลอดภัย 100%"

## สิ่งที่เจ้าของต้องทำ (ถ้าต้องการเผยแพร่บน npm)

1. สมัครบัญชีฟรีที่ https://www.npmjs.com และเปิดการยืนยันตัวตน 2 ขั้น (2FA)
2. ในเครื่องที่มี Node.js: `cd integrations/swd-sdk-js && npm install && npm test && npm login && npm publish`
3. ชื่อแพ็กเกจ `swd-sdk` ยังว่างอยู่ ณ วันที่ 7 พ.ย. 2026 (ถ้าอยากใช้ชื่อแบบ `@swd/sdk` ต้องสร้าง organization ชื่อ `swd` บน npm ก่อน ซึ่งอาจมีคนจองแล้ว)

ไม่มีค่าใช้จ่าย
