# Neuro ZETAPHY — ชั้น 1 (อ่านและอธิบายสัญญา)

งานแรกตาม "แผน ZETAPHY Chain": ตัวอ่านสัญญาที่บอกเป็นภาษาคนว่าสัญญาเหรียญบน
**BNB Chain, Base และ Arbitrum** ให้สิทธิ์อะไรกับเจ้าของบ้าง (สร้างเหรียญเพิ่ม,
บล็อกกระเป๋า, หยุดการโอน, เปลี่ยนภาษี, อัปเกรดโค้ด ฯลฯ) ต้นทุน $0

- **อ่านอย่างเดียว**: ใช้แค่ `eth_getCode`, `eth_getStorageAt`, `eth_call` ผ่าน RPC
  สาธารณะฟรี ไม่ขอเชื่อมกระเป๋า ไม่มีโค้ดส่งธุรกรรม (`src/rpc.js` ปฏิเสธคำสั่งอื่นทั้งหมด)
- **กฎตายตัว ไม่ใช้ AI**: ผลเหมือนเดิมทุกครั้ง มี `reportHash` ให้เครื่องอื่นตรวจซ้ำได้
  (ตามจุดอ่อนข้อ 1 ในแผน: งานต้องตรวจซ้ำได้)
- **ไม่เชื่อข้อความจากสัญญา**: ชื่อ/สัญลักษณ์เหรียญถูกกรองอักขระควบคุมและแสดงเป็นข้อความเท่านั้น
  ชื่อที่มีลิงก์ถูกเตือนว่าเป็นกลลวง

## ใช้งาน

```bash
npm install
node cli.js bsc 0x...            # อธิบายเป็นภาษาไทย
node cli.js base 0x... --lang en  # English
node cli.js arbitrum 0x... --json # รายงานเต็ม
npm run web                       # เปิดหน้าเว็บที่ http://localhost:8080/
```

หน้าเว็บ (`web/`) เป็นไฟล์ static ล้วน เบราว์เซอร์ของผู้ใช้เรียก RPC สาธารณะเอง
จึงวางบนโฮสต์ฟรีได้ทันที เช่น Vercel (ตั้ง Root Directory เป็น `zetaphy-neuro`,
มี `vercel.json` แล้ว) หรือ Cloudflare Pages ลิงก์แชร์ได้: `/web/?chain=bsc&address=0x...`

## สิ่งที่ตรวจ

| ผลตรวจ | ระดับ |
|---|---|
| ชื่อเหรียญมีลิงก์/ชื่อเว็บ (เหรียญหลอกแจกฟรี) | สูง |
| อัปเกรดโค้ดได้ (EIP-1967 / beacon / `upgradeTo`) | สูง |
| สร้างเหรียญเพิ่ม, บล็อกกระเป๋า, หยุดการโอน | สูง (ต่ำ ถ้าเจ้าของสละสิทธิ์แล้ว) |
| เปลี่ยนภาษี, สวิตช์เปิดปิดเทรด, เพดานต่อรายการ | ปานกลาง (ต่ำ ถ้าสละสิทธิ์แล้ว) |
| คำสั่ง `SELFDESTRUCT` | สูง |
| `DELEGATECALL` นอก proxy, ระบบสิทธิ์แบบ roles | ปานกลาง |
| สำเนา EIP-1167, เจ้าของปัจจุบัน, ยกเว้นภาษีบางกระเป๋า | ข้อมูล |

ข้อจำกัด: ตรวจจากชื่อฟังก์ชันที่รู้จัก (`src/signatures.js`) ในโค้ดบนเชน
กลโกงที่ตั้งชื่อฟังก์ชันแปลกๆ อาจหลุดได้ เพิ่มชื่อใหม่ใน `src/signatures.js`
แล้วรัน `npm run selectors`

## ขั้นต่อไปตามแผน

1. วางหน้าเว็บบนโฮสต์ฟรีและลองกับสัญญาจริงบนทั้ง 3 เชน (เครื่องที่สร้างโค้ดนี้ต่อ RPC สาธารณะไม่ได้
   จึงยังไม่ได้ลองกับ mainnet)
2. นับผู้ใช้ต่อเดือนแบบไม่เก็บข้อมูลส่วนตัว เพื่อวัดประตู "ผู้ใช้ Neuro ≥ 1,000 รายต่อเดือน"
   ก่อนลงทุนขั้น 2
3. เพิ่มการจำสัญญาที่สร้างจาก ZETAPHY launcher (ต้องมีที่อยู่ factory ของแต่ละเชน)
   เพื่อยืนยันกฎกันโกง: ภาษีลดได้อย่างเดียว ไม่มีการมินต์เพิ่ม ไม่มี blacklist หรือ pause
4. ชั้นอธิบายด้วย AI (ทางเลือก): ส่งเฉพาะผลตรวจ ไม่ให้สิทธิ์เรียกเครื่องมือ (จุดอ่อนข้อ 12)

# Neuro ZETAPHY tier 1 (English summary)

Read-only contract reader and explainer for BNB Chain, Base and Arbitrum. Fixed
rules over on-chain bytecode (no AI, no wallet, no transactions), Thai and
English output, a reproducible `reportHash`, a CLI and a static web page.
Run `npm test` and `npm run test:web`.
