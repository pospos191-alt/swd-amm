# สรุปผลการรีวิวสัญญาอัจฉริยะ ZETAPHY (ฉบับภาษาไทย)

รีวิวภายใน วันที่ 2026-10-30 ที่ commit `d07b980` รายละเอียดเต็ม (ภาษาอังกฤษ) อยู่ที่
[`manual-review.md`](manual-review.md) และรายการ property/invariant ทั้งหมดพร้อมสถานะอยู่ที่
[`invariants.md`](invariants.md)

**นี่ไม่ใช่การ audit จากบุคคลภายนอก** ผู้รีวิวหนึ่งคนอ่านสัญญาที่ถือหรือโอนเงินทุกตัวครบทั้งไฟล์ หนึ่งรอบ
และเขียน/รันชุดทดสอบเชิงคุณสมบัติ (property / invariant) ประกอบ ส่วนที่ "ไม่พบปัญหา" หมายถึง
"ไม่พบในการอ่านอย่างตั้งใจหนึ่งรอบ" ไม่ได้แปลว่า "ปลอดภัย" ก่อนขึ้น mainnet ควรแก้ข้อ High/Medium
พร้อมเพิ่ม regression test และควรให้บุคคลภายนอก audit ส่วน bridge, DEX และ NeuroJobs

ระดับความรุนแรงประเมิน **เสมือนมีมูลค่าจริงอยู่ในสัญญา** (แม้ปัจจุบันเป็น testnet)

## สิ่งที่ตรวจแล้วผ่าน (สรุป)

- **ZetaphyCheques**: ยอดเงินในสัญญา = ผลรวม (มัดจำ − จ่ายแล้ว) เสมอ, เช็คไม่จ่ายเกินมัดจำ (Halmos ตรวจเชิงสัญลักษณ์ด้วย), ไม่มีการขึ้นเงินหลังปิด, token hook re-enter ไม่ได้
- **ZetaphyOfflineOrders** (ทดสอบกับ router/pair จริงของ DEX): ไม่เหลือเงินค้างในสัญญา, nonce ใช้ได้ครั้งเดียว, ผู้ขายได้อย่างน้อย minAmountOut
- **RewardVault**: เงินเข้า = คงเหลือ + จ่ายออก, ปล่อยไม่เกิน 10% ต่อ 365 วัน (เมื่อไม่มีการฝากระหว่างทาง)
- **Bridge (Guard/Airlock/LockBoxV2)**: supply = mint − burn, ไม่ปล่อยถ้าการรับรองไม่ครบ/ยังกักตัว/ถูก veto, เพดานรายวันไม่ถูกทะลุ, หยุดชั่วคราวแล้วไม่มีเงินเคลื่อน, LockBox ถือเงินพอดีกับที่ล็อกไว้
- **NeuroJobs**: เงินในสัญญาตรงกับหนี้ทั้งหมดทุก wei และ totalActiveBond ถูกต้อง (แต่ property "ถอนเงินค้ำประกันไม่ได้ระหว่างที่ยังถูกลงโทษได้" ล้มเหลวในกรณี NJ-1 ข้างบน)
- **DEX**: swap ไม่ทำให้ k ลดลง, มูลค่าต่อหุ้น LP ไม่ลดลง, DLMM: ผลรวม bin = reserve, bin เหนือ/ใต้ราคาปัจจุบันมีเหรียญข้างเดียว, swap ไป-กลับไม่ได้กำไร, คณิตศาสตร์ mulDiv ตรงกับค่าอ้างอิง 512 บิต
- **NFTMarketplace**: เงินในสัญญา = เครดิตค้างจ่าย + ข้อเสนอที่เปิดอยู่, ทุกการขายแบ่งเงินครบราคาและส่งของจริง
