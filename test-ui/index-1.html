L. Impermanent Loss Calculator

Estimates the impermanent loss of a 50/50 constant-product LP position from a price change alone — it does NOT include trading fees earned, which can offset or exceed it. For a DLMM/concentrated position this is a rough approximation only (real IL also depends on your exact bin range).
Optional: auto-fill the current price from a live pool instead of typing it in.

P. LP Fee Earnings Estimator

Constant-product pools only — estimates fees collected by this pool over its most recent trades, then applies your CURRENT pool share retroactively. That's an approximation: it doesn't account for your share changing over time, or fees earned before you deposited. Reported per token, not combined into one currency.

T. Session PnL Tracker

Constant-product pools only — reuses the trades already fetched by My Activity above. For each pair you swapped, nets your total tokens in vs. out, then values the B-side at TODAY's pool price to approximate a combined PnL in token-A terms. This is NOT true realized P&L (it doesn't use the price at each individual fill) and ignores LP/fee activity. Refresh My Activity first for the latest trades.
Refresh My Activity above, then click Calculate.

W. What-If Add Liquidity Simulator

Constant-product pools only — previews the LP tokens and pool share a deposit would give you BEFORE you actually send it, using the standard constant-product AMM formula (proportional mint, or sqrt(A×B) for a brand-new pool). This is a general approximation, not a read of this program's own internal accounting — always double-check against Pool Info for the real result. Amounts are raw units, same convention as the Add Liquidity panel.

H. Multi-hop Swap

For two mints that don't share a direct pool — routes through one intermediate mint automatically (A → C → B) using whatever pools exist right now. Both hops are submitted in a single transaction, so it's all-or-nothing: either the whole route executes or none of it does.

G. Limit Orders (client-side)

This is NOT a real on-chain order — the program has no limit-order/keeper mechanism. An order only fires while this browser tab stays open, your wallet stays connected, and this device stays online — it checks the price roughly every 20 seconds and submits the swap for you to approve. Closing the tab, disconnecting the wallet, or losing network pauses every pending order.
No limit orders yet.

K. DCA Orders (client-side)

This is NOT a real on-chain scheduler — the program has no recurring-order mechanism. A plan only runs while this browser tab stays open, your wallet stays connected, and this device stays online: it checks roughly every 20 seconds and submits the next swap for you to approve once its scheduled time arrives. Closing the tab, disconnecting the wallet, or losing network pauses every active plan (it simply resumes catching up once you're back).
