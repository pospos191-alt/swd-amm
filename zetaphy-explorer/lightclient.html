ZETAPHYSTARK light client

STARK light client prototype · testnet

This page checks, in your browser, a hash-based STARK proof (SHA-256 + FRI, post-quantum) that validators holding the required power of a pinned validator set signed a block. It needs no RPC node and no validator list: only the 32-byte root of the set it started from.

หน้านี้ตรวจหลักฐาน STARK (ใช้แฮช SHA-256 ทนควอนตัม) ในเบราว์เซอร์ ว่าบล็อกได้รับลายเซ็นจากผู้ตรวจสอบที่มีพลังโหวตเกิน 2/3 โดยไม่ต้องเชื่อโหนด RPC และไม่ต้องโหลดลายเซ็นทั้งหมด

What is proven, what is trusted
  • Proven by the STARK (128-bit conjectured, 72-bit provable): the signer bitmap over the committed set adds up to signed power S, total T, keyless U and signer count C, and the chain's rule 3S > 2T − 3U is checked on them.
  • Signature validity depends on the proof's mode: all reveals and checks every signer's ML-DSA-44 signature (complete); sample checks power-weighted samples (k·log2(3S/(2T−3U)) bits); none trusts the prover for ML-DSA validity.
  • Trusted: the pinned genesis set root; that validators sign set handoffs (needs a chain change, see docs/future/stark-light-client.md); SHA-256.
  • Demo data is generated with public test keys. It is not a real chain.
