      Lock a MetaMask account to this wallet

      Hand control of an ECDSA account in MetaMask to this quantum-safe wallet. Its address, balance, tokens and stake stay where they are, but from now on only this wallet can move them.

      • Permanent, no undo: after the lock the chain refuses every transaction that account's MetaMask key signs, and contracts no longer accept its signatures (e.g. permits).
      • If you lose this wallet's seed, the locked account is lost too. Download the seed backup first.
      • This wallet must have sent at least one transaction on chain (so the chain knows its ML-DSA-44 public key).

      Prepare for Q-day

      Q-day is when the network stops trusting ECDSA signatures (MetaMask-style keys), because a quantum computer may forge them. From then on an ECDSA account that has not moved is frozen (its funds stay, but it cannot send). The safest way is to lock your MetaMask account to this wallet beforehand (the card above).

      Consent to a flagged contract

      With the threat gate on, the network does not deliver a transaction to a contract with an enforced Neuro flag unless the account itself consents (one transaction, at most a day). This is consent, not censorship: you can still go ahead, but read the flag's reason first.

            Cosmos wallets (Keplr, Leap, Cosmostation)

            They show the zetaphy1… address of the same account as in an EVM wallet (eth_secp256k1 key, coin type 60). They need the node's https address, which serves /rpc and /rest (nodes set up with setup-node.sh do).

            Which wallets work
            • Work now (custom networks): MetaMask, Rabby, Trust, OKX, Coinbase Wallet, Brave, Rainbow, Zerion, Frame, and Ledger/Trezor through them. Keplr, Leap and Cosmostation with the buttons above.
            • May work (not confirmed): Binance Wallet, inside the Binance app, if it accepts the network; outside the app it needs WalletConnect.
            • Not until the wallet adds ZETAPHY itself: Phantom, and wallets with a fixed list of chains.
            • Never: Solana-only or Bitcoin-only wallets. They are not EVM or Cosmos wallets.
            • Quantum-safe: only this page's own ML-DSA-44 key and the ZETAPHY Snap. Every other wallet signs with ECDSA (secp256k1), which a large enough quantum computer can break; lock such an account to this wallet to protect it.

            Keeping a larger balance safe

            A key in a web page is only as safe as the browser and the computer it runs on.

            Native PQ account: move to the ZETAPHY Snap (key inside MetaMask)

            1. Install MetaMask (Flask until the snap is published).
            2. Lock this wallet, then click "Connect MetaMask".
            3. Copy the new account's zetaphy1… address.
            4. Unlock this wallet again and send the funds to that address.

            EVM accounts: a hardware wallet

            1. Connect a Ledger or Trezor to MetaMask or Rabby.
            2. Add the ZETAPHY Testnet network to it.
            3. Send the funds to the hardware account's 0x… address.
