# BZTPHY: แต้มรางวัลช่วง testnet แลกเป็น ZETAPHY จริงตอน mainnet

คนที่ช่วยรันเชน ZETAPHY ช่วงทดลอง (validator และ Neuro runner) ได้แต้ม **BZTPHY** ทุกวันโดยอัตโนมัติ
เมื่อเปิด mainnet แต้มทั้งหมดจะถูกแปลงเป็น **ZETAPHY จริง** ใส่ใน genesis ของ mainnet ให้ที่อยู่เดิม

## ได้แต้มอย่างไร (ต่อวัน UTC)

| ทำอะไร | ได้เท่าไร |
|---|---|
| เป็น validator (bonded ไม่ถูก jail) | 100 BZTPHY × uptime (เช่น ออนไลน์ 95% ได้ 95) ต้อง uptime อย่างน้อย 50% |
| เป็น Neuro runner | 2 BZTPHY ต่องานที่ส่งผลตรวจ (reveal) สูงสุด 50 ต่อวัน |

- แต้มเข้าที่อยู่ EVM (0x…) ของบัญชี validator หรือ runner เอง ดูได้ใน MetaMask (Import token ด้วยที่อยู่ BZTPHY)
- ระบบ GitHub Actions คำนวณจากข้อมูลบนเชนแล้วแจกทุกวันเวลา 00:23 UTC (07:23 น. เวลาไทย)
- เครื่องแรกของทีม (`zetaphy-validator-0`) ไม่ได้แต้ม ทีมมีส่วนแบ่งของตัวเองอยู่แล้ว

## แลกเป็น ZETAPHY จริง

- กองรางวัล: **10,000,000 ZETAPHY** (1% ของทั้งหมด) แบ่งจากส่วน rewards 50%
- ตอนเปิด mainnet ทีมเสนอโหวต `freeze` ปิดการแจกแต้ม แล้วแบ่งกองตามสัดส่วน:
  `ZETAPHY ที่ได้ = 10,000,000 × แต้มของคุณ ÷ แต้มทั้งหมด`
- ใช้วิธีแบ่งตามสัดส่วนเพื่อไม่ให้สัญญาเกินกองที่มี ใครทำงานนานและสม่ำเสมอได้มาก
- คำนวณซ้ำได้ทุกคน: `node zetaphy-network/scripts/points.js snapshot --pool 10000000`

## กติกา

- **BZTPHY โอนไม่ได้ ขายไม่ได้ อนุมัติให้ใครใช้ไม่ได้** (สัญญาปฏิเสธเอง) เป็นหลักฐานว่าใครทำงาน ไม่ใช่ของซื้อขาย
  ใครเสนอขาย BZTPHY หรือ "ZETAPHY ล่วงหน้า" คือมิจฉาชีพ
- 1 คน 1 validator: ใครเปิดหลาย validator หรือ runner ปลอมเพื่อเก็บแต้ม governance ถอนแต้มคืนได้ (`revoke`)
- แจกได้ไม่เกิน 5,000 BZTPHY ต่อวันรวมทุกคน ถ้ากุญแจที่แจกรั่ว ความเสียหายจำกัดอยู่วันเดียวและถอนคืนได้
- เจ้าของสัญญาคือ governance ของเชน (ZetaphyTimelock) การถอนแต้ม เปลี่ยนเพดาน หรือ freeze ต้องผ่านโหวต
- อัตราแต้มอาจปรับได้ด้วยโหวต จะประกาศล่วงหน้า

## ข้อควรรู้

- mainnet จะเปิดหลังผ่านการตรวจสอบความปลอดภัย (audit) เท่านั้น ยังไม่มีกำหนดวัน
- หน้านี้เป็นแผนของโครงการ ไม่ใช่สัญญาทางกฎหมาย และไม่ใช่การเสนอขายหลักทรัพย์หรือโทเคน
  ก่อนแจกจริง ทีมจะตรวจกฎของ ก.ล.ต. เรื่องสินทรัพย์ดิจิทัลในไทย

## สำหรับผู้ดูแล

- เปิดใช้: Actions → `rewards` → Run workflow → `deploy` (ใช้ secret `ZETAPHY_DEPLOYER_KEY` เป็นผู้แจก, owner = timelock)
  แล้ว merge branch `rewards/testnet` ที่ได้ หลังจากนั้นแจกเองทุกวัน
- แจกย้อนหลังวันใดวันหนึ่ง: `rewards` → `award` และใส่เลขวัน (UTC day = unix time ÷ 86400) ระบบไม่จ่ายซ้ำ
- ปรับอัตรา: ตั้ง `POINTS_CONFIG` เช่น `{"validatorDaily": 120}` ใน workflow
